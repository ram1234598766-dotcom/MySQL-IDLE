# MySQL IDLE

MySQL IDLE is a Tkinter desktop client for MySQL/MariaDB with a mobile companion.

Windows `.exe` builds and Android `.apk` builds are produced by GitHub Actions. See the Actions tab after pushing the full project files.

> The Android app is a WebView client for the desktop companion; it does not embed MySQL credentials or start a database server. Use the companion only on a trusted network unless HTTPS has been configured.
